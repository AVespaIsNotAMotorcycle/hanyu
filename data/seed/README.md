# Hanyu Seed Dataset

Generated by the pipeline in [`data/`](../README.md) (`npm run data:build`). Don't edit these files by hand. `manifest.json` records the dataset version, a content hash, and the SHA-256 of every source used.

| File                     | Contents                                                                    | License                  |
| ------------------------ | --------------------------------------------------------------------------- | ------------------------ |
| `words.json`             | 11,000 HSK 3.0 word notes: forms, pinyin, definitions, frequency, ordering  | CC BY-SA 4.0             |
| `characters.json`        | 3,088 character notes: readings, traditional forms, introduction order      | CC BY-SA 4.0             |
| `character-details.json` | Character definitions, radicals, decompositions, etymologies                | LGPL-3.0-or-later        |
| `strokes.json`           | Stroke SVG paths and medians for handwriting                                | Arphic Public License    |
| `grammar.json`           | 593 HSK 3.0 grammar points                                                  | Syllabus reference data  |

Files are split by license so each one carries a single set of obligations.

## Sources and Attribution

- **HSK 3.0 syllabus** (《HSK考试大纲》, Center for Language Education and Cooperation / Chinese Testing International, November 2025). Word, character, and grammar lists are used as reference data; the syllabus document itself is not republished. Transcriptions come from [uranbekanarbaev/hsk-3.0-vocabulary-dataset](https://github.com/uranbekanarbaev/hsk-3.0-vocabulary-dataset) (words) and [krmanik/HSK-3.0](https://github.com/krmanik/HSK-3.0) (grammar and character lists), checked against the official PDF.
- **CC-CEDICT** ([cc-cedict.org](https://cc-cedict.org/)), published by MDBG, licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Supplies traditional forms, definitions, and syllable boundaries in `words.json` and `characters.json`. Changes: entries were matched to syllabus words by pinyin, and citation tones follow the syllabus.
- **wordfreq** by Robyn Speer ([rspeer/wordfreq](https://github.com/rspeer/wordfreq)), data licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Supplies Zipf frequencies in `words.json`. wordfreq's Chinese data includes **SUBTLEX-CH** (Cai, Q., & Brysbaert, M. (2010). SUBTLEX-CH: Chinese word and character frequencies based on film subtitles. _PLoS ONE_, 5(6), e10729). SUBTLEX is freely available data.
- **Make Me a Hanzi** by skishore ([skishore/makemeahanzi](https://github.com/skishore/makemeahanzi)). `character-details.json` derives from its `dictionary.txt` (Unihan and CJKlib, LGPL-3.0-or-later). `strokes.json` derives from its `graphics.txt` (Arphic PL KaitiM GB and UKai fonts, Arphic Public License).
